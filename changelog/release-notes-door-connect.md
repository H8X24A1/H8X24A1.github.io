# HXA.io Door Connect for Microsoft Teams

## v.1.0.0
Release date: 2026-08-03

+++ New :icon-shield-check:
- [x] Door Connect Launch: First release of Door Connect — a smart building access control and visitor management solution fully integrated with Microsoft 365 and Microsoft Teams.
- [x] Calling Button: Visitors can initiate a live Microsoft Teams call with the responsible person or team directly from the Door Connect display.
- [x] Chat Button: Visitors can send a written message directly from the Door Connect display — delivered instantly to a configured Microsoft Teams channel.
- [x] Concern Button: Visitors can select a pre-configured concern from the display and it is sent automatically to the configured Microsoft Teams channel — no typing required.
- [x] Portal Configuration: Admins can create, configure, and manage all Door Connect buttons directly from the HXA Portal — assigning button types, Teams accounts, and channels per location.
- [x] Microsoft Teams Integration: Door Connect is fully integrated with Microsoft 365 — all visitor interactions are routed through Microsoft Teams channels and accounts.
- [x] Onboarding Support: Door Connect can be activated during the HXA onboarding flow or from the Connectors page in the Portal.
