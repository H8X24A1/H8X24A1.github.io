# HXA Display

## Optional Local Exchange Connection

With the local Exchange connection add-on, HXA Room Booking on an HXA Display can access an on-premises Exchange Server directly via EWS over the local network. Calendar data is not routed through HXA.io Services; function settings, configuration, and licensing continue to use HXA.io Services.

The EWS connection details and credentials are configured directly on the display. See [Local Exchange Connection via EWS](/setup/connector-setup/microsoft-exchange/local-ews-connection.md) for the connection model and requirements.
